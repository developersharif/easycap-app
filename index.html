FAQ

Common questions about EasyCap

Everything you need to know before getting started.

Why does Windows Defender show a warning?

EasyCap does not carry a code signing certificate, which is expensive for an independent developer. Windows Defender flags unsigned installers by default, so the warning reflects the missing certificate rather than anything found in the software.

To install:

  1. Click “More info” when the Windows Defender message appears.
  2. Select “Run anyway” to continue the installation.
  3. Allow screen recording permissions when prompted.
Who develops EasyCap?

EasyCap is built and maintained by a solo developer, @developersharif, who is committed to making free, efficient tools for content creators. Larger companies can afford certificates; here the resources go into features and maintenance instead. The source code is available for review.

What is the difference between screenshot and recording modes?

Screenshots capture a selected area and open in the built-in editor for annotations and effects. Screen recording captures your full screen, which keeps quality and performance predictable. Selected-area recording is in development for a future release.

Is EasyCap safe to use?

Yes. The Windows Defender notice comes from the missing code signing certificate, not from the software's behaviour. EasyCap:

  • Contains no malware or bundled programs
  • Collects no personal data
  • Requests only the permissions it needs to record
  • Is updated and maintained regularly
What are the system requirements?

EasyCap runs on Windows 7, 8, 10, and 11. Recommended:

  • 4 GB RAM minimum
  • 100 MB free disk space
  • Any modern CPU
  • No dedicated graphics card required
How do I get support?

Support for this solo-developed project runs through:

  • GitHub issues for bug reports
  • Email, answered within 24 to 48 hours
  • Online documentation
  • Community discussions
